# 真实物理电路 · RealCircuit

一个用于 **Minecraft Java 版 26.2（Fabric）** 的直流电路仿真教学模组。基于**节点电压法（MNA）**实时求解电路，让你在游戏里搭建真实可计算的直流电路，观察电流、电压、灯泡亮度、短路烧毁等物理现象。

> 模组仅面向**创造模式**，所有元件均可在创造物品栏直接获取，无需合成。

---

## 一、核心功能

- **真实电路求解**：放置/拆除导线或元件、调节变阻器与电源时自动重算，电流电压即刻更新。
- **丰富元件库**：
  - 定值电阻（5 / 10 / 20 / 50 / 100 / 200 / 500 / 1000 Ω，共 8 档）
  - 滑动变阻器（20 / 50 / 100 / 200 Ω，共 4 档，右键 GUI 实时调节）
  - 直流电源（1.5 / 3 / 6 / 9 / 12 V，共 5 档）+ 学生电源（右键 GUI 调压）
  - 机械电流表 / 机械电压表（一体化 3 格长条模型，**双量程**，超量程损坏）
  - 电子电流表 / 电子电压表（单方块，永不损坏）
  - 小灯泡（0.3V/0.2A、2.5V/0.3A、3.8V/0.3A，**亮度随电流三档变化**，过载烧毁）
  - LED、开关、保险丝（过载熔断）、铜导线（红石粉式连接线，**支持竖直连接**）
- **原版方块导电**：铁块、铜块等原版可导电方块可直接充当导线——把电路中的铜导线全部替换成铜块，只要总电阻在允许范围内，小灯泡依然可以点亮。
- **严格极性**：红面为正(+)、黑面为负(−)，电表接反显示负读数。
- **故障与保护**：短路→电源烧毁（起火爆炸）；元件过载→烧毁并冒白烟；机械电表超量程→损坏；用电器被导线旁路时不爆炸，仅不工作。
- **读数交互**：右键电表查看实时读数与当前量程（黑底白字界面）；右键变阻器/学生电源弹出调节界面。
- **成就系统**：内置新样式进度成就——「真实物理电路」「简易电路图」「短路！请停止这种行为」「串联电路」「并联电路」，搭建对应电路自动解锁。

## 三、安装步骤

1. 为 Minecraft 26.2 安装 **Fabric Loader**（使用 Fabric 官方安装器）。
2. 下载 **Fabric API** 对应 26.2 的版本，放入 `mods` 文件夹。
3. 将本模组的 `realcircuit-1.0.0.jar`（见仓库 `release/` 目录）放入 `mods` 文件夹。
4. 启动游戏，新建/进入世界，开启**创造模式**即可在物品栏找到全部元件。

> 典型路径：`.minecraft/mods/realcircuit-1.0.0.jar`

## 四、操作指引

### 1. 搭建电路
- 用**铜导线**连接各元件（导线会自动连接相邻的导线与元件，支持水平与**竖直**方向连接）。
- 也可用**铁块、铜块等原版可导电方块**充当导线：它们自带微小电阻，整段替换铜导线后电路依然导通。
- 元件有正负极朝向：放置时正面朝向你；红(+)/黑(−)面需接对。
- 电源的正极面接出电流，经用电器回到负极面，形成回路。

### 2. 电表使用（机械款，3 格多方块）
- 放置后自动展开为 3 格长条：**左格黑柱=公共端(−)**，**中格红柱=小量程(+)**，**右格红柱=大量程(+)**。
- 电流表须**串联**在被测支路；电压表须**并联**在被测两点。
- 黑公共端必接；接中格红端=小量程（高精度），接右格红端=大量程。
- 右键电表任意一格查看**当前量程**与**读数**。
- 超量程会损坏电表（三格变红、不导通），需重新放置。

| 电表 | 小量程 | 大量程 |
|------|--------|--------|
| 电流表 | 0–0.6 A（高精度） | 0–3 A |
| 电压表 | 0–3 V（高精度） | 0–15 V |

### 3. 变阻器 / 学生电源
- 右键滑动变阻器 → GUI 拖动滑块改变阻值，电路实时重算。
- 右键学生电源 → GUI 调节输出电压。

### 4. 开关 / 保险丝 / 灯泡
- 开关右键切换通断；保险丝电流过大即熔断（保护电路）。
- 灯泡**亮度随电流分三档**（光照等级 5 / 10 / 15）：电流低于额定电流 10% 时不发光，电流越大越亮；过流或反接会烧毁。

### 5. 成就
- 「真实物理电路」：放置任意电路元件。
- 「简易电路图」：用电源 + 导线 + 开关 + 小灯泡搭出最简单电路并点亮灯泡。
- 「短路！请停止这种行为」：发生电源短路。
- 「串联电路」/「并联电路」：让两个发光小灯泡分别处于串联 / 并联关系。

## 五、注意事项

- 本模组为教学目的，**仅在创造模式使用**，不提供生存合成表。
- 注意**极性**与**量程**：电表接反仅读数为负，不会损坏；但超量程会损坏机械电表。
- 短路会导致电源烧毁并伴随爆炸，请按真实电路规范接线。
- 电路在“放置/拆除导线或元件、调节变阻器/电源”时自动重算；若数值未刷新，检查导线是否正确连接到元件的 +/− 面。
- 铁块/铜块等原版可导电方块可充当导线（自带微小电阻）；原版红石粉**不参与**本模组电路。
- 用导线把小灯泡或电阻**旁路**（用电器短路）不会引发爆炸：灯泡仅不发光，电阻仅不起作用；但若旁路导致电源正负极直接被短接，仍会触发电源短路爆炸。

## 七、仓库结构

```
realcircuit/
├─ README.md                 本文档（简介 + 使用说明）
├─ release/
│  └─ realcircuit-1.0.0.jar  可直接安装的模组文件
├─ src/main/
│  ├─ java/com/realcircuit/  全部源代码
│  └─ resources/assets/realcircuit/  资源（模型/贴图/语言）
├─ build.gradle / gradlew.*  Fabric Loom 构建脚本
└─ .gitignore
```

源码目录说明：
- `block/` `blockentity/`：方块与方块实体逻辑
- `circuit/`：电路求解核心（图、元件、MNA 求解器）
- `world/CircuitWorldManager.java`：世界内电路的构建、求解与结果应用
- `client/`：读数与调节 GUI
- `registry/`：方块/物品/物品栏注册
- `network/`：客户端↔服务端 GUI 数据同步
